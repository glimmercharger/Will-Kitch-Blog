# Will Kitch Blog

This repo is a Jekyll blog using the Minima theme and is set up to publish through GitHub Pages.

To add a post, create a Markdown file under `_posts/` with date-based naming and front matter like this:

```md
---
layout: post
title: My Post Title
---

Your content here.
```

For local development, run `bundle install` once, then `bundle exec jekyll serve`.
